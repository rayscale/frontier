## Usage

```tsx
import { Avatar } from '@rayscale/frontier'

export function Example() {
  return (
    <Avatar>
      <Avatar.Image src="/team/ana.jpg" alt="" />
      <Avatar.Fallback>AM</Avatar.Fallback>
    </Avatar>
  )
}
```

An avatar shows the image once it has loaded. Until then, and when the image fails, it shows the fallback, so the space never looks empty. With no children, it shows a placeholder person.

## API reference

### Avatar

Renders a `<span>` and forwards its attributes. Compose `Avatar.Image`, `Avatar.Fallback`, or both as its children. The table lists the props `Avatar` adds.

| Prop       | Type                                              | Default    | Description                                               |
| ---------- | ------------------------------------------------- | ---------- | --------------------------------------------------------- |
| `size`     | `'small' \| 'medium' \| 'large' \| 'extra-large'` | `'medium'` | Size of the avatar, shared by the image and the fallback. |
| `children` | `ReactNode`                                       | —          | `Avatar.Image`, `Avatar.Fallback`, or both.               |

### Avatar.Image

Renders an `<img>` and forwards its attributes. The image stays hidden until it loads, and nothing renders when both `src` and `srcSet` are missing.

### Avatar.Fallback

Renders a `<span>` with content that shows until the current image has loaded, and again if it fails.

| Prop       | Type        | Default | Description                                |
| ---------- | ----------- | ------- | ------------------------------------------ |
| `children` | `ReactNode` | —       | Text, a symbol, or other fallback content. |

## Accessibility

<Callout title="Decide whether the avatar names someone">
  Next to a visible name, the avatar is decoration, so give its image `alt=""`. When the avatar
  stands alone, describe it with the `alt` of the image, such as the name of the person.
</Callout>

- The image is a native `<img>`, so `alt` is read as for any other image.
- The placeholder person is hidden from assistive technology.
- Initials in a fallback are read as text. Keep them short, and do not rely on them alone to identify someone when the name is not shown.
