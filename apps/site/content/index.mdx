Frontier is a design language for the web. It defines the principles, foundations, patterns, and components behind an interface, and this site documents its React implementation, `@rayscale/frontier`.

The guidelines state design intent. The package implements it and does not extend it.

## What is in the package

- **Components** — React components built on native HTML, with composable parts and a documented API.
- **Symbols** — A set of symbols that share one grid and one stroke.
- **Typeface** — Geist, the variable typeface of the system, with its weights and usage.
- **Styles** — Design tokens and component styles in one stylesheet, with a light and a dark mode.
