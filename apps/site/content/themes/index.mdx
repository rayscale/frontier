A theme changes how Frontier looks without changing how it works. It keeps the roles, the contrast, the focus, and the behavior that the guidelines require, and it changes values such as color, radius, and border width. Every theme defines both modes, light and dark.

Choose a theme below, and the whole site follows it. The choice is remembered on this device.

## Conformant and extended

A theme is one of two kinds, and it says which.

- **Conformant.** It changes only the values that the guidelines leave open, such as the colors of the roles. It is Frontier in another voice.
- **Extended.** It departs from a guideline on purpose, for example by using another typeface. It names every departure with its reason, and the page of the theme shows them.

An extended theme can depart from how Frontier looks, never from whether people can use it. Every theme meets the same contrast requirements in both modes, and the build fails when one does not. The rules are in the [Themes guideline](/docs/guidelines/foundations/themes).

## Use a theme

Import the stylesheet of the theme after the main one, and set `data-theme` and `data-mode` on the element where the theme applies. It can be the root element or any region inside it.

```tsx
import '@rayscale/frontier/styles.css'
import '@rayscale/frontier/themes/bisnes.css'
```

```html
<html data-theme="bisnes" data-mode="dark"></html>
```

A page that offers a choice of theme can load every theme with `@rayscale/frontier/themes.css`. Set `data-theme="frontier"` to restore the default theme inside a region.

Set `data-theme` and `data-mode` together on the same element. A region then does not depend on the mode around it.

Every theme has a page in this section with a live preview in both modes. [Create a theme](/docs/themes/creating) to add your own.
