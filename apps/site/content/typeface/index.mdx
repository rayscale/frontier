Frontier is set in Geist, a variable sans-serif. The stylesheet loads it through `@fontsource-variable/geist`, so nothing needs to be installed or configured separately.

<Callout title="Frontier Sans is in the backlog" tone="info">
  Frontier Sans, an original typeface, is being developed in the repository. It is not used by the
  interface yet, and the package does not ship it.
</Callout>

## Weights

One axis, `wght`, runs from 300 to 900. Frontier uses 400 to 700.
