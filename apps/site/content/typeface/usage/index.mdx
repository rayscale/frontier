The Frontier stylesheet already sets text in Geist. Nothing needs to be configured when `@rayscale/frontier/styles.css` is imported.

## The family token

`--frontier-font-family` lists Geist first, then the system font, then the generic `sans-serif`. The system font is the fallback while Geist loads or when it is unavailable. It is not a second typeface to choose.

```css
.title {
  font-family: var(--frontier-font-family);
  font-weight: var(--frontier-font-weight-semibold);
}
```

## Weights

Use the weight tokens, and the axis supplies every value between them.

| Token                             | Weight |
| --------------------------------- | ------ |
| `--frontier-font-weight-regular`  | 400    |
| `--frontier-font-weight-medium`   | 500    |
| `--frontier-font-weight-semibold` | 600    |
| `--frontier-font-weight-bold`     | 700    |

Hierarchy comes first from size and then from weight, so a page rarely needs more than two weights.

## Numerals

Figures are proportional by default. Use tabular figures where numbers are compared or stacked, such as counters and tables.

```css
.table {
  font-variant-numeric: tabular-nums;
}
```
