The Frontier stylesheet already sets text in Frontier Sans. Nothing needs to be configured when `@rayscale/frontier/styles.css` is imported.

## The family token

`--frontier-font-family` lists Frontier Sans first, then Outfit, then the generic `sans-serif`. Outfit is the fallback while the font loads or when it is unavailable. It is not a second typeface to choose.

```css
.title {
  font-family: var(--frontier-font-family);
  font-weight: var(--frontier-font-weight-semibold);
}
```

## Weights

Use the weight tokens, and the axis supplies every value between them.

| Token                             | Weight |
| --------------------------------- | ------ |
| `--frontier-font-weight-regular`  | 400    |
| `--frontier-font-weight-medium`   | 500    |
| `--frontier-font-weight-semibold` | 600    |
| `--frontier-font-weight-bold`     | 700    |

The font also has a Light master at 300 for display text. Hierarchy comes first from size and then from weight, so a page rarely needs more than two weights.

## Numerals

Figures are proportional by default. Use tabular figures where numbers are compared or stacked, such as counters and tables.

```css
.table {
  font-variant-numeric: tabular-nums;
}
```

A slashed zero is available where `0` and `O` must not be confused.

```css
.code {
  font-feature-settings: 'zero';
}
```

## Files

The compiled font is exported as `@rayscale/frontier/fonts/*`. The stylesheet declares the font face for you, so most projects never reference the file.

## Build it from source

The source, the build pipeline, and the tests live in `packages/frontier/source/typeface`. Its README describes the workflow.
