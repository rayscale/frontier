## Usage

```tsx
import { Button } from '@rayscale/frontier'

export function Example() {
  return <Button>Save</Button>
}
```

## API reference

### Button

Renders a native `<button>` and forwards its attributes together with the Motion props. The table lists the props `Button` adds.

| Prop       | Type                                                                       | Default     | Description                                                        |
| ---------- | -------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------ |
| `variant`  | `'primary' \| 'secondary' \| 'outline' \| 'ghost' \| 'danger'`             | `'primary'` | Visual appearance.                                                 |
| `size`     | `'small' \| 'medium' \| 'large' \| 'icon' \| 'icon-small' \| 'icon-large'` | `'medium'`  | Button size. The icon sizes are square.                            |
| `disabled` | `boolean`                                                                  | `false`     | Disables the button and its interaction animations.                |
| `asChild`  | `boolean`                                                                  | `false`     | Renders the child element with the button styles and interactions. |
| `children` | `ReactNode`                                                                | —           | Button content.                                                    |

## Accessibility

<Callout title="Name every icon-only button">
  A button with only an icon has no text for assistive technology. Give it an accessible name with
  `aria-label`.
</Callout>

- Buttons default to `type="button"`, so they do not submit a form by accident.
- A disabled button uses the native `disabled` attribute and leaves the tab order. Do not hide information that only a disabled button holds.
- Hover and press animations respect the reduced motion preference.
- The focus ring comes from the focus tokens and shows for keyboard focus.
