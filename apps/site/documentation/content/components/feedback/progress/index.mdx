## Usage

```tsx
import { Progress } from '@rayscale/frontier'

export function Example() {
  return <Progress value={60} aria-label="Upload progress" />
}
```

Use progress when a task takes long enough that someone wonders whether it works. Pass `value` to show how far it has come, from `0` to `max`. Leave `value` out when the length is unknown, and the bar shows that work is going on.

## API reference

### Progress

Renders a `<div>` with the `progressbar` role and forwards its attributes. The table lists the props `Progress` adds.

| Prop         | Type                                                                          | Default     | Description                                                                                                  |
| ------------ | ----------------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------ |
| `value`      | `number`                                                                      | —           | Current progress, kept between `0` and `max`. Leave it out for indeterminate progress.                       |
| `max`        | `number`                                                                      | `100`       | Value that means the task is done. Zero, negative, and non-finite values fall back to `100`.                 |
| `thickness`  | `number \| string`                                                            | —           | Height of the bar or stroke width of the ring. A number is pixels, and a string is any CSS length.           |
| `color`      | `'primary' \| 'success' \| 'danger' \| string`                                | `'primary'` | Color of the indicator. A name uses its token, and any other string is used as CSS.                          |
| `trackColor` | `'subtle' \| 'default' \| 'strong' \| string`                                 | `'default'` | Color of the track. A name uses its border token, and any other string is used as CSS.                       |
| `animation`  | `'smooth' \| 'none'`                                                          | `'smooth'`  | `smooth` animates changes and the indeterminate movement. `none` turns both off.                             |
| `variant`    | `'linear' \| 'circular'`                                                      | `'linear'`  | Shape of the indicator.                                                                                      |
| `size`       | `'small' \| 'medium' \| 'large'`                                              | `'medium'`  | Thickness of the bar. For a ring, the diameter, which also takes a number in pixels or any CSS length.       |
| `radius`     | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'full' \| number \| string` | pill shape  | Corner radius of the track. Only for the linear variant. A number is pixels, and a string is any CSS length. |

## Accessibility

<Callout title="Name every progress bar">
  Progress has no visible label of its own. Give it an accessible name with `aria-label`, or point
  `aria-labelledby` at a nearby heading, so people know what is in progress.
</Callout>

- The element has the `progressbar` role, with `aria-valuemin` set to `0`, `aria-valuemax` set to `max`, and `aria-valuenow` set to the value.
- An indeterminate progress leaves out `aria-valuenow`, so assistive technology does not report a value that does not exist.
- Color is never the only message. Pair `success` and `danger` with text that states the result.
- With the reduced motion preference, changes and the indeterminate movement do not animate.
