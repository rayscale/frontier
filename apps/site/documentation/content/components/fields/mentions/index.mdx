---
title: Mentions
description: Opens a list of choices when people type @ or / in a text field, and inserts the one they choose.
---

## Usage

```tsx
import { Mentions, Textarea } from '@rayscale/frontier'

const people = [
  { id: 'ana', label: 'Ana García', insert: '@ana' },
  { id: 'ben', label: 'Ben Carter', insert: '@ben' },
]

export function Example() {
  return (
    <Mentions triggers={[{ char: '@', items: people, label: 'People' }]}>
      <Textarea label="Comment" />
    </Mentions>
  )
}
```

Mentions adds a list of choices to a text field. When people type a trigger, such as `@` for a person or `/` for a command, a list opens at the cursor. They filter it by typing, move through it with the arrow keys or the pointer, and choose an item to put it in the text.

It wraps the field instead of replacing it, so you keep the field you already use: a [textarea](/documentation/components/fields/textarea), an [input](/documentation/components/fields/input), or the field of an [input group](/documentation/components/fields/input-group). The field keeps its own value and works controlled or not. Mentions renders no element around it.

The text is plain: choosing "Ana García" inserts what `insert` says, such as `@ana`, and nothing else. It does not turn the mention into a chip. Read the mentions from the text when you need them.

## API reference

### Mentions

Wraps a text field. It renders the field and a wrapper that adds nothing to the layout.

| Prop            | Type                                            | Description                                                                   |
| --------------- | ----------------------------------------------- | ----------------------------------------------------------------------------- |
| `children`      | `ReactElement`                                  | The text field to watch, or a group that holds it.                            |
| `triggers`      | `TMentionTrigger[]`                             | The triggers, each with its own list.                                         |
| `onQueryChange` | `(query: string, trigger: string) => void`      | Called with the text typed after a trigger, each time it changes.             |
| `onSelect`      | `(item: TMentionItem, trigger: string) => void` | Called with the item that people chose, and the trigger that opened the list. |

### Trigger

| Property      | Type                                                      | Default             | Description                                                           |
| ------------- | --------------------------------------------------------- | ------------------- | --------------------------------------------------------------------- |
| `char`        | `string`                                                  | —                   | The text that opens the list. It must come at the start of a word.    |
| `items`       | `TMentionItem[]`                                          | —                   | The choices.                                                          |
| `atStart`     | `boolean`                                                 | `false`             | Opens the list only when the trigger is the first thing in the field. |
| `filter`      | `false \| (item: TMentionItem, query: string) => boolean` | Search of the label | Decides which items match. `false` shows them all.                    |
| `insertSpace` | `boolean`                                                 | `true`              | Adds a space after the inserted text.                                 |
| `label`       | `string`                                                  | `'Suggestions'`     | Name of the list for assistive technology, such as `People`.          |

### Item

| Property      | Type        | Description                                                  |
| ------------- | ----------- | ------------------------------------------------------------ |
| `id`          | `string`    | Tells the item apart from the others.                        |
| `label`       | `string`    | Name of the item. People search it.                          |
| `description` | `ReactNode` | A second line, such as an email or what a command does.      |
| `icon`        | `ReactNode` | Shown before the label, such as an avatar. It is decorative. |
| `insert`      | `string`    | The text to insert. Defaults to the trigger and the label.   |
| `disabled`    | `boolean`   | Keeps people from choosing the item.                         |

## Accessibility

<Callout title="The focus stays in the field">
  The list never takes the focus. People keep typing, and the field points at the highlighted item
  with `aria-activedescendant`, so a screen reader announces each item as the arrow keys move.
</Callout>

- The arrow keys move through the list and skip disabled items. Enter or Tab chooses, and Escape closes it. While the list is open these keys do not reach your own handlers, so Enter does not send a message that is half written.
- The list is a listbox named after the trigger, such as "People", and each item is an option.
- The field gets `aria-autocomplete`, `aria-controls`, and `aria-activedescendant` while the list is open.
- A status message says how many suggestions there are.
- The list closes when the field loses focus, and when nothing matches.
- The keys are ignored while people compose text with an input method, so choosing a character does not choose an item.
