Icons are simple, single-color pictograms drawn on a shared grid. They carry meaning quickly and stay legible at small sizes. Every icon is a React component exported from the package.

## Usage

```tsx
import { Button, Plus } from '@rayscale/frontier'

export function Example() {
  return (
    <Button>
      <Plus aria-hidden="true" />
      New file
    </Button>
  )
}
```

An icon is decorative: it is hidden from assistive technology, and the control that contains it carries the accessible name.

## How icons are drawn

- Icons are drawn on a 24 × 24 grid, with the artwork inside a 20 × 20 safe area.
- Every icon uses a 2 px stroke with round caps and joins, and `currentColor`, so it follows the text color.
- Size an icon with the `size` prop, in pixels or as any CSS length. The default is 24.

## Movement

Every icon moves in one way that matches its meaning. Arrows and chevrons nudge along their direction. A plus, a cross, and a gear turn. A check and a pulse draw themselves. A bell rings, and a warning shakes. A loader sweeps. Documents, folders, and boxes lift. Tools such as a pen or a search tilt, and the rest pop.

The control that holds the icon starts the movement, so an icon moves when its control is hovered, focused, pressed, or highlighted. Any button, link, tab, menu item, or option is such a control, and disabled ones do not start it. Icons return to the icon as drawn when the control is left.

Movement is removed when the reduced motion preference is on, and the icon stays as drawn. Never rely on movement alone to show a state.

### Your own controls

Mark any other element with `data-icon-trigger` to let it start the movement of the icons inside it.

```tsx
<a href="/next" data-icon-trigger>
  Next
  <ArrowRight />
</a>
```

## API reference

### Icon

`Icon` renders an `<svg>` from the shapes of an icon and forwards the native SVG attributes. Most code uses the named icons instead, such as `Plus`, which are made with `createIcon`.

| Prop       | Type                                                                                                   | Default                  | Description                                                                  |
| ---------- | ------------------------------------------------------------------------------------------------------ | ------------------------ | ---------------------------------------------------------------------------- |
| `iconNode` | `TIconNode`                                                                                            | —                        | The shapes to draw on the 24-unit grid.                                      |
| `size`     | `number \| string`                                                                                     | `24`                     | Width and height in pixels or as a length.                                   |
| `motion`   | `'nudge-up' \| 'nudge-right' \| 'nudge-down' \| 'nudge-left' \| 'turn' \| 'draw' \| 'ring' \| 'sweep'` | the movement of the icon | The kind of movement. Built-in icons choose their own.                       |
| `animate`  | `boolean`                                                                                              | —                        | Plays the movement while `true`, and once when the icon appears with it set. |

### createIcon

`createIcon({ name, iconNode, motion })` returns an icon component. The component also exposes the shapes it draws as `iconNode`. `motion` is optional and sets the movement of the new icon.

## Accessibility

<Callout title="Icons are decorative">
  Icons are hidden from assistive technology. Name the control that holds an icon, never the icon
  itself.
</Callout>

- Do not rely on an icon alone to carry a meaning that a word can state.
- An icon-only control needs an accessible name and, where the meaning is not universal, a visible text alternative.
