Icons are simple, single-color pictograms drawn on a shared grid. They carry meaning quickly and stay legible at small sizes. Every icon is a React component exported from the package.

## Usage

```tsx
import { Button, Plus } from '@rayscale/frontier'

export function Example() {
  return (
    <Button>
      <Plus aria-hidden="true" />
      New file
    </Button>
  )
}
```

An icon is decorative: it is hidden from assistive technology, and the control that contains it carries the accessible name.

## How icons are drawn

- Icons are drawn on a 24 × 24 grid, with the artwork inside a 20 × 20 safe area.
- Every icon uses a 2 px stroke with round caps and joins, and `currentColor`, so it follows the text color.
- Size an icon with the `size` prop, in pixels or as any CSS length. The default is 24.

## API reference

### Icon

`Icon` renders an `<svg>` from the shapes of an icon and forwards the native SVG attributes. Most code uses the named icons instead, such as `Plus`, which are made with `createIcon`.

| Prop       | Type               | Default | Description                                |
| ---------- | ------------------ | ------- | ------------------------------------------ |
| `iconNode` | `TIconNode`        | —       | The shapes to draw on the 24-unit grid.    |
| `size`     | `number \| string` | `24`    | Width and height in pixels or as a length. |

### createIcon

`createIcon({ name, iconNode })` returns an icon component. The component also exposes the shapes it draws as `iconNode`.

## Accessibility

<Callout title="Icons are decorative">
  Icons are hidden from assistive technology. Name the control that holds an icon, never the icon
  itself.
</Callout>

- Do not rely on an icon alone to carry a meaning that a word can state.
- An icon-only control needs an accessible name and, where the meaning is not universal, a visible text alternative.
