# Content

Content defines how Frontier speaks. Interface text is part of the design: it carries meaning, sets tone, and must survive translation and right-to-left layouts.

## Guidelines in this category

- [Voice](./voice.md): the character of the language and what it refuses.
- [Writing](./writing.md): labels, actions, errors, empty states, numbers, and direction.

## Relationship to the other categories

Voice follows the [Principles](../principles/README.md), particularly clarity and restraint. Writing follows [Typeface](../foundations/typeface.md) for case and [Accessibility](../foundations/accessibility.md) for names and errors. [Messages](../patterns/messages.md) and [Forms](../patterns/forms.md) apply these rules to specific surfaces.

## One vocabulary

The same concept uses the same word everywhere. A synonym is not variety; it is a second thing for the reader to learn. Terminology is decided once and recorded in [Voice](./voice.md).

## Principle

Text should say what the interface means, in the fewest words that remain clear.
