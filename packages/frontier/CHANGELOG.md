# @rayscale/frontier

## 0.1.0-alpha.2

### Minor Changes

- **Breaking:** `Drawer` is renamed to `Sheet`. Update the imports and the part names.

  New components: `AlertDialog`, `Carousel`, `Chart`, `ColorPicker`, `ColorSwatch`, `CreditCard`,
  `CursorCard`, `HoverCard`, `ImageZoom`, `InputGroup`, `InputOTP`, `Lightbox`, `Magnifier`,
  `Mentions`, `NumberField`, `Rating`, `Resizable`, `Stepper`, `Textarea`, and `Timeline`.

  Also: `Callout` can be dismissed, and `Dialog.Content` takes `initialFocus`.
